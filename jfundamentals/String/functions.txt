What you want--->Java functions
Length---->s.length()
Get one character---->s.charAt(i)
Slice--->s.substring(1, 4) (end is excluded, same as Python)
Slice from index to end--->s.substring(2)
Find position-->s.indexOf("a") (returns -1 if not found)
Last position--->s.lastIndexOf("a")
Check in ---->s.contains("ab")
Starts / ends with---->s.startsWith("a") / s.endsWith("a")
Upper / lower---->s.toUpperCase() / s.toLowerCase()
Strip space----> s.trim()
Replace-----> s.replace("a", "b")
Split----> s.split(" ") or s.split("\\s+") (returns String[])
Join----> String.join(",", arr)
Repeat---->s.repeat(3)
Compare equal---->s.equals(t) (never ==)
Ignore case compare---->s.equalsIgnoreCase(t)
Empty check	----> s.isEmpty()
String to list of chars----> s.toCharArray()
Reverse	----> new StringBuilder(s).reverse().toString()
Count a character----->no built-in: use a loop
